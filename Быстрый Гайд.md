1. Установите Docker + Docker Compose
2. Настройте firewall (все порты кроме 22, 80, 51820 могут быть закрыты с наружи)
3. Установите пароль и имя пользователя в настройках wg-easy, adguardhome
3. docker compose up -d

# Команды для настройки firewall
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw allow 51820/udp
sudo ufw enable
