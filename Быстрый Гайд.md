1. Установите Docker + Docker Compose
2. Установите amneziawg-dkms
3. git clone https://github.com/canntstand/VPN-quick-setup
4. Переименуйте .env.example в .env и укажите переменные
5. docker compose up -d
6. Зайдите в wg-easy (8080 порт) и adguardhome (8081 порт) 
7. Настройте правила обфускации в wg-easy + другие свои настройки в wg-easy и adguard home
8. Выполнить команды ниже

```
sysctl -w net.ipv4.ip_forward=1
sysctl -w net.ipv6.conf.all.forwarding=1
echo "net.ipv4.ip_forward=1" >> /etc/sysctl.conf
echo "net.ipv6.conf.all.forwarding=1" >> /etc/sysctl.conf

iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
iptables -A FORWARD -i wg0 -j ACCEPT
iptables -A FORWARD -o wg0 -m state --state RELATED,ESTABLISHED -j ACCEPT
```
