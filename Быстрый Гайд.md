2. Настройте firewall (все порты кроме 22, 80, 51820, 8080, 8081 могут быть закрыты снаружи)
3. Установите amneziawg-dkms
4. docker compose up -d

6. Настройте правила обфускации в wg-easy + другие свои настройки в wg-easy и adguard home
