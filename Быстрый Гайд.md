1. Установите Docker + Docker Compose
2. Установите amneziawg-dkms
3. Переименуйте .env.example в .env и укажите переменные
3. docker compose up -d
4. Зайдите в wg-easy (8080 порт) и adguardhome (8081 порт) 
5. Настройте правила обфускации в wg-easy + другие свои настройки в wg-easy и adguard home
6. Выполнить команды ниже

```
sysctl -w net.ipv4.ip_forward=1
sysctl -w net.ipv6.conf.all.forwarding=1
echo "net.ipv4.ip_forward=1" >> /etc/sysctl.conf
echo "net.ipv6.conf.all.forwarding=1" >> /etc/sysctl.conf
```
